2026-10-14 · Observatory v0.0.12 · Windows x64 / Node 24.19.0

结论：发现并修复多处可污染产品判断的采集及统计缺陷。修复后的入口可以隔离身份不明、终态未知、口径不明及不可核验的保存数据；现有历史的覆盖不足，不能据此声称跨 Agent 成本、稳定性或产品能力排名可靠。所有旧 Trial、Outcome、归档与 Agent 原始日志保持原样。

范围与责任

核对原生源发现、只读 SQLite、适配器事件/调用/usage 提取、共享指标、缓存/API、采集器时间锚点、独立会话绑定、Console 不可变归档/快照与总览统计和绘图。主归属 Observation & Evidence，Console 复用这一层并承担 Presentation/Delivery 与 Closed-loop/Governance 的保存和统计，不重新评分。保留进入检查前已有的未提交改动，没有提交或覆盖这些改动。

缺陷与修复

等级原风险最终处理
P1Console 直接读 metrics.json，绕过清单封印及文件哈希；只有 object/trial_id 的键会跨运行/任务串值。复用归档校验，按 evaluation_run_id/task_id/object/trial_id 关联；明确 session/self 与日志准入门禁，重复会话归属排除；诊断显示不可核验数据。
P1逐字段保留首个有效值，混合多个采样版本；新版缺失会借旧值。显式快照可能采到缓存。每 Trial 选最新整份已验证归档；快照只补没有归档的 Trial，新快照请求 fresh=1 并写独立 SHA-256 封印。旧未封印快照可阅读但不进入图表；不改写历史。
P1Mobilework/opencode 在缓存包含关系未知时把 input/output 相加；零分项被 || null 吃掉，缺失被默认加零。共享 token-metrics 引擎保留真零、分项覆盖、源包含关系与 profile。去重 usage 身份、优先 session 范围，拒绝冲突；不确定的全会话总量 null。历史未知 Token 总量隔离出总览。
P1SQLite 非零退出/解析失败静默返回 []；list 回退会损坏换行、分隔符、SQL null。CLI -readonly + 有界超时；编码异常使用 Node 内置 SQLite readOnly 无损读取同一 SQL；读取失败显式报错。Windows 子进程隐藏，仅结束本次超时查询进程。
P1Codex 工具一律 ok、未知 Turn 当 error；DSH 开始/工具调用直接当成功；Codex 两类成功率重名。保留 unknown/running/cancelled 与明确失败；区分 success_rate/tool_success_rate。未知终态的零错误数保持 null，已见错误仅部分覆盖；调用数不能冒充原生结果事件数。
P1generation span 结束冒充首输出；无 session ID 的代理按时间窗借给会话，响应到达当首 token。WorkBuddy 完成 span 不补 TTFT；Mobilework 代理必须明确 session membership 与首输出锚点，未绑定代理记录不能填会话 TTFT。Codex/opencode 派生输出事件仍不声称原生首 token。
P1Pass@5 对任意 ≥5 次取至少一次，Pass^5 按目录 mtime 及删除 unknown 后的连续序列推算。按运行、任务版本、评分范围、对象、轨道与策略分组；只有恰好五条不同且全部已评分 Trial 才算 Pass。未知/额外执行不连成成功序列；Pass^5 是五次全成功，mtime 不恢复实验顺序。
P1下划线任意字段绕过白名单，调用/指标/诊断 API 未统一白名单过滤，正文可通过诊断 message 出站。取消下划线旁路，诊断正文不进入白名单；调用/指标/失败与摘要 API 使用 redact + whitelistFilter。对话正文接口不再返回 Prompt/模型正文；保留结构化元数据。
P2负时长/非法数字、累计 Token 当 max_context、部分样本当完整；不同版本/单位/profile 混合，比例求和及 100% 格式错。非法数字和时钟冲突 null；取消累计 Token 峰值回退；partial/captured 分开计数。混合口径不汇总；比例 sum=null，仅完整一致 numerator/denominator 才 pooled_rate；前端按类型显示比例与覆盖。

使用与遗留边界

首次复核时运行服务仍加载旧后端；后续已按用户授权核验中断、追加审计并升级 8780/8790，最新回执见本页末尾。缺失新增口径的旧档保持原样，不能通过修改 CSV、填零或复制近邻会话回填。显式补采记录新的采样时间，不能冒充任务结束时的原始事实。

原生源持续变化时，导出是有界读取窗口，不是跨客户端事务快照。摘要 success_rate 只描述调用终态，业务成功仍依赖独立 Outcome。全任务成本、失败任务成本、不同任务/模型/评分范围的样本偏差需另行分组分析；只对通过任务画消费图存在选择偏差。错误日志模式属于观察证据，不是根因证明。严格原生 Trace 准入与 release_eligible 不由这些修复升级。供应链来源签名与 SQLite 上游原件来源仍按依赖清单的既有缺口处理；跨平台、每版客户端及真实 CDP/Hook 新采集未在本次验收。
